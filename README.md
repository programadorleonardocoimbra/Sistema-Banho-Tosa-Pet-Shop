## 📌 Sobre o projeto

O **Sistema Banho & Tosa — Pet Shop** é um projeto Back-End desenvolvido em **Java** para representar e organizar regras relacionadas ao fluxo de atendimento de um Pet Shop, com foco especial em serviços de **banho e tosa**.

Mais do que um exercício de sintaxe, este projeto foi criado com o objetivo de praticar a construção de software a partir de um **problema de negócio real**, trabalhando raciocínio lógico, organização do código, modelagem do domínio e evolução incremental da aplicação.

O repositório faz parte do meu portfólio de estudos e desenvolvimento em **Java Back-End**.

---

## 🎯 Objetivos

Este projeto foi desenvolvido para exercitar e demonstrar conhecimentos importantes para o desenvolvimento Back-End, como:

- Aplicação de **lógica de programação** em um cenário de negócio;
- Organização de um projeto Java;
- Criação e manipulação de regras de domínio;
- Separação de responsabilidades no código;
- Utilização de classes, objetos, atributos e métodos;
- Tomada de decisão através de estruturas condicionais;
- Tratamento de fluxos e dados da aplicação;
- Escrita de código legível e de fácil manutenção;
- Utilização de **Git e GitHub** para versionamento;
- Evolução de um projeto simples para uma arquitetura mais robusta.

## 💡 Problema de negócio

Um Pet Shop precisa lidar diariamente com informações relacionadas aos pets e aos serviços executados durante o atendimento.

A proposta deste projeto é representar esse processo através de uma aplicação Java, centralizando as regras do sistema e criando uma base que possa evoluir para uma solução completa de gestão.
